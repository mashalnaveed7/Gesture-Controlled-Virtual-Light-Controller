# Gesture-Controlled Virtual Light Controller

A Computer Vision project that allows users to control a virtual light using hand gestures.

## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
- Pygame

## Planned Gestures

- Open Palm - Turn Light ON
- Fist - Turn Light OFF
- Index Finger - Move Light
- Pinch - Control Brightness
- Two Fingers - Change Light Color
